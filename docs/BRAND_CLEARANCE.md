# Preliminary brand-clearance record

Date checked: 2026-08-27. This engineering record is not legal advice or a substitute for a qualified trademark search.

Exact-expression searches found no live `SENDARC` record in the USPTO, WIPO Global Brand Database, or KIPRIS interfaces at the time checked. However, there are material collision and search-quality risks:

- `SENDMARC` is an active EU word mark in class 42 owned by an operating email-security company. It differs from SendArc by one letter and overlaps the email/software market. [WIPO record](https://branddb.wipo.int/en/similarname/brand/EM500000018834699)
- A pre-existing `SENDARC` remittance/software project and associated accounts use the same expression. [GitHub repository](https://github.com/6figuresdev/SENDARC)
- `sendarc.com` and `sendarc.xyz` were already registered/used by others when checked.
- ARC is also an email-authentication term defined by [RFC 8617](https://datatracker.ietf.org/doc/html/rfc8617), which can weaken search distinctiveness.

The engineering recommendation was to rename before public launch. The product owner explicitly decided to retain **SendArc**, so implementation continues under that name. Before spending money on a domain, code-signing identity, advertising, or a broad public launch, obtain a professional similarity/common-law search for the intended markets and relevant classes (at least software/SaaS classes 9 and 42, and class 38 if applicable).
